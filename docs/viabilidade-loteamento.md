# Estudo de viabilidade preliminar de loteamento

Documentação completa: `app-web/docs/viabilidade-loteamento.md`.

SINAPI automático: botão **Atualizar SINAPI** sincroniza as 27 UFs da competência (`POST /api/viabilidade/sinapi/sync`). O estudo usa só a UF selecionada.

Abrir a partir do CAD (aba Loteamento) → **Estudo de viabilidade** → `/viabilidade/[projetoId]` ou `/viabilidade/local`.
